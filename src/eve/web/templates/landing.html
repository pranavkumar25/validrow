Why Unknown is a feature

Most verifiers round Unknown up to Valid.

It flatters the report and it costs you the sender reputation. Gmail, Outlook and Yahoo accept almost any recipient at the door and bounce it later, so a naive probe reads "accepted" and calls it deliverable. Validrow knows which providers do this and refuses to report a confident Valid for them.

The same rule runs everywhere. A catch-all domain accepts every address, so its 250 proves nothing and the address comes back Risky, not Valid. A greylisted address is deferred, not answered, so it is retried on a schedule rather than written off. A DNS timeout is credited to DNS, never to a probe that never ran.
